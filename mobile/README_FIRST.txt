NMTS MOBILE COMPLETE UI FINAL — QR URL VERSION
Version: 1.1.1
Android versionCode: 3

IMPORTANT FLOW
1. app.json does NOT contain a fixed website/API URL.
2. Enter user name and mobile number in the app.
3. Tap "Scan NMTS Pairing QR".
4. The QR generated by NMTS Web must contain:
   issuer: NMTS_SLEEPING_STOCK_PAIRING
   version: 2
   mobile_user_id
   pairing_code
   pairing_token
   api_base_url (or apiBaseUrl)
5. The app accepts HTTPS URLs only.
6. The API URL is saved with the encrypted device session in SecureStore.
7. All future API calls use the saved URL automatically.

VISIBLE UI CHANGES
- Results/details stay at the top.
- Search, scan, quantity, Add to List and Submit stay at the bottom.
- Stock Verification supports multiple parts before submit.
- Stock Availability supports manual, pasted and camera-scanned multiple parts.
- Request response shows straight part rows and accepted quantity input.
- Part OCR scans only the centre box crop.
- No scan sound; successful part scan gives vibration only.
